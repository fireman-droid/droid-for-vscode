## 健壮性修复与验证

- Fork/Compact 的后端操作已经成功但恢复元数据保存失败时，连接转为不可用并明确
  说明已生成后继；后续发送与会话写入被阻断，Retry 可重新连接，History 可找回后继。
  后继已接管后发生最后一次保存失败，也会发布正确会话身份，避免页面继续持有旧 ID。
- 恢复中的首次 daemon 状态查询最多尝试 3 次，间隔 500ms；持续异常或 unknown
  保留后台状态未知，显示 Retry/Stop 入口，不伪报完成或自动派发队列。Process 模式
  依据新建进程且不支持后台轮次的能力，将不能续接的旧轮次标为 interrupted 并暂停队列。
- 尚待 Host 确认的本地发送保留回合身份和用户消息；同会话的较早快照不能抹去它。
  匹配的回合响应或快照才确认发送，跨会话清理，不放宽对未知回合增量的过滤。
- 未发队列保留每会话 10 条、每条 200,000 字符上限，独立于 1,000,000 文本单位
  的恢复元数据预算；最多 8 个恢复会话。合法长队列不再使整份恢复索引失效或因正文
  体积驱逐元数据，旧格式中的合法队列也按同一预算读取。
- Review Undo 按工作区真实路径隔离日志，跨进程事务锁覆盖恢复、全部文件写入和
  日志删除；相同工作区的旧共享日志在锁内迁移，其他工作区日志保留。会话租约复用
  同一互斥实现保护失效锁回收；释放争用或读取失败明确报错，保留所有权供重试。
- 编辑器内计划的批准取 Host 最新正文，不采用尚未同步的页面缓存；超长计划被拒绝
  后解除该次提交锁，即使同一消息批次已收到缩短后的 ready，也能继续批准或拒绝。
- 两种 daemon 子进程包装都立即监听 error；等待启动期间的错误进入初始化失败
  通道，pid 缺失后的异步错误也不会成为未处理事件。
- 本轮 `pnpm run typecheck`、`pnpm run lint:budgets`、`pnpm run package:vsix` 和
  `pnpm run verify:vsix` 均通过；80 条目 VSIX 已安装到 Cursor，9 项生产文件哈希一致。
  未新增、修改或运行测试、浏览器自动化或真实故障注入。所有使用 Droid 的窗口需
  Reload 才采用新锁协议；跨进程并发与真实交互仍待人工验收。安装 CLI 的既有

## 当前架构与数据权威

- Droid CLI/SDK 是会话和执行权威。Runtime 适配 Process/daemon，Host 持有会话、
  请求、权限、文件和恢复所有权，共享 Bridge 严格校验，Webview 只消费展示状态。
- SDK 保持 0.7.0，使用公开 `DaemonSessionController`、`MultiSessionStateManager`
  与窄 facade；不访问 `.sessions.controller`，不为展示创建竞争会话连接。
  未完成跨 SDK/CLI 版本兼容验收，不能由类型声明推断完整产品能力。
- Chat、Models、Mission、Viewer、Review 五个生产入口使用 V2；交互复用
  `packages/chat-ui/src/ui/` 的 shadcn/Radix，AI 展示复用 `ai-elements/`。
  已统一到 `src/webview-v2`，旧 `src/webview` 目录及 V1 页面、入口、样式已移除。
- 前端状态、Host 消息接线、Bridge、聊天功能、Models/Mission/Review/Viewer 业务
  均在同一根目录按职责归位；公共 UI 和算法直接引用 `packages/chat-ui`，不保留 V1 转发。
  `useAnswerScroll` 负责回答获确认后的滚动，ChatApp 负责装配。
- 本轮迁移 144 个仍用实现/测试文件，删除 134 个 V1 专属文件和旧转发层；
  混合测试保留原 V2 断言，移除 3 项专属直接依赖及 17 项不再被引用的锁文件包。
  Host 与 Webview 各自检查所属源码，不再由旧 UI 依赖间接提供 DOM 类型。
- Host `runtimeLifecycle` 保留启动/替换编排，准备与激活、工作区变化、清理、身份
  校验分别由邻近模块负责；Mission/模型发现取消由所属 state 方法完成。
  `turnFlow` 仅保留发送/消费，事件投影、停止/结算、Spec 接管和重试各有入口与窄 Port。
  这不是所有状态的类级封装；IDE/Mission 等仍有受身份校验约束的协调写入。
  [架构指南](ARCHITECTURE.md) 提供源码阅读顺序、状态负责人及常见修改入口。
- `@droidvisx/chat-ui@0.1.0` 提供独立 ESM、类型、作用域 CSS 与本地字体；
  Droid 协议、Host、Runtime、VS Code 适配留在仓库业务层。包已独立构建/打包，
  尚未发布 npm，也未验证接入其他 CLI 项目；没有接入 Claude/Codex 执行后端。
- 恢复存储只保存选择、Conversation/backend 关联、队列、活动轮次及 Diff 元数据。
  聊天正文从 Droid 历史恢复，不提前展示另一份本地全文缓存；旧 V2 全文负载迁移
  时剥离并写入 V3，保留 Factory 源数据、快照和既有图片文件。
- New/Fork/Rewind 创建独立 Conversation；Compact/Spec Handoff 可在同一
  Conversation 内采用 successor backend。无可靠消息身份时保留索引但不猜展示位置。
- Fork/Rewind 继承的轮次保留原执行会话 ID，供 Review 查找原文件快照；轮次版本号
  按新 Conversation 重置。恢复解码接受这类跨 Conversation 的轮次来源，并修正旧版
  复制过来的越界版本号，避免 Reload 时丢弃已选的新会话。重新生成回复也使用 Rewind。
  62 项定向会话恢复回归、类型与文件预算检查通过；未连接真实模型或改写真实会话。
  完整生产构建与 80 条目 VSIX 校验通过，已安装 Cursor，9 项生产文件哈希一致；
  需 Reload Window 加载，实际会话恢复由用户验收。
  若旧版本已丢弃并覆盖恢复索引，需要从历史列表重新选择仍保存在 Droid 中的会话；
  不自动猜测应切换到哪个分支，也不改写 Factory 聊天文件。
- Runtime replacement、工作区切换、请求和回合使用身份/代次检查；旧异步结算仅将
  自己的 Changes 合并到最新状态，不持有旧全文覆盖新消息。持久写入成功才确认 revision。
- 发布给页面的边界诊断只记录类型、序号、身份、状态、长度及耗时，不记录正文、
  Thinking、命令或凭据。安全 Markdown 禁止原始 HTML；Canvas 使用零网络隔离沙箱。

## 连接、启动与历史恢复

- 后台发现按批核验监听 PID/命令身份，最多 6 并发并共享同次扫描；已确认失效的
  精确登记可清理，真实活动任务保留，身份未知时拒绝猜测或重复启动。
  PID 被其他程序复用不再被当作仍运行的 Droid；不按旧登记杀当前 PID。
- 元数据、模型与预热不再串行堵在主会话恢复前；目录加载失败保留原恢复目标。
  页面仅在 Runtime 和权威历史都可用后开放发送，提供 `host.perf.activation-ready`。
- JSONL 历史可使用一次只读快照，固定读取边界，上限 256 MiB；修复父链并按身份
  去重/排序，保留原显示预算。未知格式或读取不稳定回退到 daemon 分页，再回退
  Process；不改源文件、不伪造缺失历史。Compact/Handoff 可沿关联加载前段历史。
- SDK 会话目录读取内部的同步文件扫描移到懒启动、复用的 Node Worker；
  返回值和 Date 保持 SDK 语义，不添加结果缓存，扩展关闭时释放 Worker。
- 主聊天使用独立 daemon 和本地 IDE relay，以所在窗口/工作区接入官方 Factory
  IDE 服务。缺少服务时普通聊天仍可用，IDE 如实显示不可用；代价是额外进程及冷启动。
- 只有根会话完成 initialize/initialized/tools list 和初始编辑器通知，才确认
  IDE connected。其他子会话或旧日志不能代替握手；握手超时 60 秒，心跳超时 75 秒。
- daemon 空闲回收 worker 后，发送先恢复同后台/同会话，再等待新 IDE 握手；
  取消不会偷偷重发，迟到旧代次不覆盖当前连接。
- 顶部 IDE 连接详情卡片已移除，状态原因通过共享 Tooltip 在悬停／聚焦时显示，
  断开时直接提供紧凑重连图标。保留 Host 重连资格、请求等待及失败反馈；普通空闲
  断开不作为连接失败强调，连接中不允许重复请求。
- 短 SSE 断流可有界续接；SDK 连接恢复后重新认证、订阅同一根会话并补齐当前轮。
  已提交内容不重发、不因短断流自动中断；缺少终态证据时保持未确认状态。
- 失效原生 IDE 客户端可安全重建，但须满足空闲、无活动子代理/BTW/受管终端及
  可靠持久历史等条件。旧活动任务继续保留；运行中 Reload 不保证无缝 IDE 重连。
  旧任务结束后可自动尝试一次恢复，失败保留草稿与暂停队列，允许手动重连。
- 新完整握手成功后清除对应旧失败提示。会话租约和 daemon 登记的原子替换有界
  重试并串行写入；永久错误仍报告，不能把存储损坏当作空表。
- Webview 先监听再加载 HTML；初始化结束补完整快照，旧 replay 进行中收到新页面
  ready 会排队再同步。启动自动同步从 5 秒退避至 30 秒并继续重试，隐藏时暂停，
  重新可见补同步；有效的已结算状态到达后停止。
- 页面在 store 应用消息后回传精确 pageId 与 sequence；迟到旧页面 ACK 无效，
  后续增量 ACK 不掩盖中间漏收。可见页面 2 秒未确认即补权威快照，连续未确认最多
  补 3 次；新 ready 或重新可见开启新的补同步机会，不重放用户请求或工具。
  确认完整快照可覆盖此前普通状态缺口；Plan 文档独立确认/补发，普通快照不冒充其正文。
  计划关闭或会话切换后清理旧身份，待确认队列只存序号、身份与时序，不复制正文。
- 快照包含仍待回答的权限/AskUser/Plan；失效身份和已关闭交互不复活。
  `postMessage=true` 仅证明平台接受投递，新增 ACK 证明页面状态已应用，不保证 DOM
  已完成绘制；`transcript.commit` 诊断也不能替代视觉验收。
- 手动 Refresh 只请求当前状态，等待同会话且比请求更新的完整快照；10 秒无响应
  显示未收到状态并重新开放刷新，不永久禁用按钮，也不重启会话或重发消息。
- Stop 未获终态确认时继续锁定该轮并允许重试，不用 watchdog/空闲超时伪造成功。
  设置更新期间拒绝发送并关联具体请求，失败只恢复尚未被用户改写的草稿。
- 回合失败与连接不可用分开提示：只有 `connection.status=unavailable` 才展示重连
  按钮；模型请求失败不再引导创建新会话，保留继续发送和切换模型的既有入口。
  SDK 错误事件和最终结果中的原因经过凭据过滤、终端字符清理和 2,000 字符限长，
  用于失败消息及恢复快照，结算不再覆盖成通用 Runtime 错误。只有最终结果携带的
  原因也写入历史；未知原因使用通用失败说明，不猜测为模型配置或断连。
  已通过类型检查、文件预算和完整构建，80 项 VSIX 校验通过并安装到 Cursor，
  9 项安装产物哈希一致；未新增、修改或运行测试及浏览器自动化，真实交互待验收。

### Restore 与 CLI 兼容限制

- 原生 Rewind 已恢复文件、后继会话 attach 失败时，运行时和 Host 保留待接管标记。
  相同消息重试只做接管，不重复恢复文件；更换锚点明确拒绝。后继提交后先 adopt，
  后续发送仍须等待新 IDE 握手；等待不再在 8 秒时清空，失败保留编辑稿和恢复入口。
- 该标记仅存于当前 Runtime 生命周期，尚不保证跨 Reload 保留；最新修正未对
  用户真实工作区执行 Restore，不能称为完整恢复验收通过。
- CLI 0.228 的 shared-process worker 跳过 IDE 初始化；当前为独立 daemon 复制
  官方 feature snapshot，只覆盖 `shared_process_agents=false`，不改全局缓存。
  文件保留到对应 daemon 登记移除；其他 flags/configs 同时冻结于该 daemon 生命周期。
  这是依赖 CLI 私有行为的兼容措施，升级后必须重新核对。
- 已用隔离 daemon 和本地模拟 IDE 服务完成真实启动/恢复握手，未调用模型、
  未操作原有会话；这一结果不代替真实 Cursor 的空闲、断线和 Restore 工作流验收。

  长列表限高滚动；点击输入框或流式更新不重置折叠状态。文件数只含当前／最近
  回合的已确认工具操作，行数为已保留补丁的操作累计，缺失不补零、不当作 Git
  净变化。沿用现有 Bridge 与 Host Review 路由，不引入工作区快照或示例数据。
- Slash 技能列表移除底部常驻详情，候选保留单行简介；悬停显示浮动预览，View
  固定打开可滚动描述并提供关闭操作。同一列表只显示一个预览，悬停不抢输入焦点，

  不明确副作用不当作成功，不用工作区快照填补缺补丁。用户手动保存只在主动打开的
  工作区比较中显示，Execute 无可靠归属时不能断言作者。

  uncertain。Add 覆盖写入使用实际修改类型，缺旧内容不编造；异常 hunk 保留可识别
  片段及明确缺口。混合受限文件只隐藏该文件，不抹去其他文件的完整证据。
- 进行中按文件显示操作详情，真实结束后每轮一张汇总卡，默认三个文件可展开更多。
  停止但未确认终态仍显示处理中；累计操作行数不等于整轮净 Diff，未知行数不写成零。
  子代理证据按真实 origin/parent 身份归属，不靠描述匹配；不把子代理总和冒充父直接修改。

  文件清单不截到 200 项，大清单虚拟化，长 Diff 分块读取；保持完整范围、文本选择、
  修改块导航、当前选择与审阅版本。内容变而计数不变也会失效刷新。
  Unified Diff 的隐藏测宽仅保留最长可打印 ASCII 行；Unicode/tab 行继续按原生排版
  测量，不复制整份 ASCII 补丁做隐藏布局，也不截断可读正文。
- writing scope 仅刷新受影响文件，合并刷新队列，拒绝迟到响应；失败可重试且不标记
  已审阅。settled 比较使用固定版本，不混入后续编辑；缺历史基线不能补造。
- daemon Branch 使用 SDK committed，Workspace 使用 SDK unstaged（包含暂存、
  未暂存、未跟踪）；默认补丁来自 SDK，扩展上下文/原生 Diff 用固定基线加 SDK 补丁。
  Staged 为 HEAD→Index，Unstaged 为 Index→工作树；Process 保留本地 Git 路径。
  不能从 SDK 名称推断它只包含普通未暂存文件。
- 非 Git 根目录/嵌套项目使用存储区私有 Git 快照，不修改用户 index，仍要求本机 Git。
  未捕获的忽略文件不当作新建，缺失 before/after 明确不可用；仅 CRLF/LF 表示差异
  的采集问题已统一私有索引规范化，不通过忽略空白掩盖真实编辑，也不重写旧快照。
- 历史片段没有完整比较证据时只读，不伪造 Native Diff、上下文、审阅或恢复能力。
  预览有大小/编码限制，二进制、非 UTF-8、过大或缺基线分别说明。
- 操作自动撤销仅支持完整、已确认、可逆的 ApplyPatch 文本更新；Edit/Create/删除/
  移动、缺证据、链接、未保存编辑、跨会话顺序不明、重叠/歧义匹配等拒绝自动撤销。
  明确 unchanged 不阻止其他完整操作。整轮上限 200 文件，超量拒绝整批但可逐文件。
- Undo 先预览确认，精确反向匹配与字节复核后写入；拒绝 BOM/混合行尾等不可可靠
  逆转情况，保留不冲突的新编辑。逐文件写前日志/写后验证支持故障恢复，冲突日志
  保留且不覆盖后续编辑；这不构成跨进程原子事务。
- 运行中不提供撤销；切换会话/scope 使旧确认失效。历史编辑 Restore 与操作 Undo
  是不同流程：SDK 恢复范围可能包含工作区外文件，UI 有界展示 basename/动作/省略数，
  不隐藏不可恢复计数。恢复列表打开的是当前文件，不是恢复目标的前后正文。
- Commit 保留原确认边界，检查完整 Index，拒绝夹带未选暂存项，失败保留草稿；
  不自动清理暂存或 push。Agent Review 使用独立 `/review` 会话与只读 Viewer，
  不宣称精确审查单次操作/Index，也不代替用户改变 reviewed 状态。
- SDK Git 比较已完成隔离 14 项断言；撤销有临时文件验证。最新聊天归因、混合受限
  证据、完整 Cursor Review/真实恢复仍待验收，不能由浏览器片段推断作者隔离已完美。
