# 用产品时发现问题，写哪里

只记这一件事。截图放 `docs/debug/image/`，条目写进下面四个分册之一。  
**不要**新开总清单，**不要**写进 `docs/product/` 或 `docs/archive/`。

| 碰到什么 | 打开哪个文件 |
| --- | --- |
| 行为不对：卡死、点了没反应、恢复丢内容、显示错 | [`debug/bug.md`](./debug/bug.md) |
| 样子不对：布局、颜色、卡片、主题、间距 | [`debug/style-refactor.md`](./debug/style-refactor.md) |
| 子代理 / agent 团队看不懂、接不上、预览不对 | [`debug/explore-subagent.md`](./debug/explore-subagent.md) |
| 想多一个能力：命令、跳转、管理页 | [`debug/feature-extend.md`](./debug/feature-extend.md) |

拿不准 → 先写 [`debug/bug.md`](./debug/bug.md)。

## 一条怎么记

1. 接着现有编号往下编（四个分册共用一套编号，现在到 38）。
2. 一行现象 + 截图路径。
3. 状态先标 `未做`。
4. 修完再改成 `待实机验收` / `已完成`，并写版本号。
