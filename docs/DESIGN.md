# 设计规则

这里记录当前有效的交互与视觉约定。具体尺寸、能力和默认值以共享组件、主题 token
及当前 SDK 契约为准；历史对标、施工步骤和逐次验收从 Git 历史查阅。

## 智能补全服务设置

- 代码续写和下一步编辑使用独立设置分区及开关，共享总开关、触发和上下文选项。
  编辑预测的地址和模型不进入 FIM 协议列表；保持已有 FIM 值，关闭预测时收起其服务字段。
- 两套密钥只显示各自配置状态，保存时由 Extension Host 密码框输入；取消任一密钥框时不写入本次配置。

## 共享样式与整改基准

设置页中用户认可的简单、紧凑、实用的控件，是后续主聊天及其他页面的复用基准，
不限于模型选择器。先修共享实现，再检查本次受影响的消费者，不为各页面复制一套 CSS。
不同入口按可用空间组合控件，不能将设置页的宽布局直接套到窄聊天面板。

| 共性内容 | 复用位置或约定 |
| --- | --- |
| Button、输入、选择、菜单、页签、弹层 | `packages/chat-ui/src/ui/`，Radix 管理键盘、焦点、Portal 与禁用 |
| 设置分组与行 | `SettingsSection`／`SettingsRow`；单层细边框、横向分隔、标题在左、控件在右，窄屏换行 |
| 搜索与筛选 | `ListToolbar`；左侧搜索，右侧筛选，窄屏换行 |
| 分页 | `Pagination`；实际范围与计数，不能把尚未加载的批次伪装成已知总数 |
| 模型与强度 | `ModelPicker`；只展示真实能力，Droid 来源过滤和保存由适配层负责 |
| 滚动条 | `ScrollArea`；覆盖式轨道，中性滑块，悬停加深、拖动强调；静态样式隐藏 viewport 原生滚动条，不依赖运行时注入样式，保留键盘与滚动语义 |
| 选中指示 | `SelectionIndicator`；下划线或背景按控件语义选择，背景使用共享 active 状态色 |
| 颜色、间距、边框与动效 | 共享主题和组件样式；Factory 配色、编辑器 Auto 映射留在 Droid 适配层 |
| 回复、代码、Diff、AI 状态 | 公共 chat／review／ai-elements 展示层；业务状态通过数据、回调与插槽接入 |

主聊天尚未整体迁移设置页的新控件。后续按明确任务逐步复用，保留草稿、IME、文字选区、
虚拟列表与滚动跟随，不把外观统一当成行为改写。
整改方法见 [项目 skill](../.agents/skills/practical-ui-refinement/SKILL.md)。

## 信息与控件密度

- 属于同一个值的信息连续显示，例如“模型名 · 等级”；先消除无必要的固定宽度和
  自动空白，再考虑增加容器。短值随内容收紧，长值截断或换行，操作箭头保持可见。
- 正文和操作分层；工具详情按需展开，不为单个省略号、状态或说明额外占一行。
  提示只说明当前行动需要知道的内容，错误保留可恢复原因。
- 设置分组使用 12px 圆角；常规控件使用共享圆角和轻边框。管理页控件常用 30px 高，
  弹出项 28px 行高；普通 Select 与触发器同宽并受视口约束。不要把这些尺寸套到所有场景。
- Composer 模式与“＋”菜单沿用模型列表的紧凑密度：模式用图标、单行名称和勾选标记，
  “＋”菜单及技能、MCP、插件子页与输入框同宽，密度通过内部行高与间距调整，保留视口宽度约束。
  子页列表统一用共享 ScrollArea，内容在列表边界裁切；说明放在标题下方，不在列表底部叠加说明白带或横线。
- 保留清晰的 `focus-visible`。按钮、菜单和页签文字不可误选；正文、代码、工具输出、
  引用原文和编辑中的文字仍可选择。正文中的路径操作必须区分拖选与点击。
- Mission 创建面板的说明型开关行不使用整行悬停／按下底色，反馈保留在开关本身；
  执行设置折叠入口只改变文字与箭头状态。底部操作沿用共享 Button 默认 28px 高，宽度随内容。
  三类代理的模型列表支持名称／ID 搜索，搜索与来源筛选叠加，不清空已选值，重新打开时清除搜索。

## 默认设置与模型选择

- 会话使用“历史记录／默认设置”，Mission 使用“任务列表／默认设置”。会话默认项
  分基础、Spec、上下文压缩和子任务；Mission 分编排者、执行与验证、里程碑验证。
- 保存只提交本页修改，失败保留草稿；撤销回到最近读取或保存成功的值。默认设置
  作用于新会话，不能切换当前聊天。锁定项显示真实原因。
- 模型主菜单按需分“推理强度／模型”两行；子菜单保留搜索、来源分组、当前勾选。
  主菜单 200px、模型列表 280px，并随可用空间收缩。纯模型场景直接打开列表。
- 主聊天模型弹层底部的“计划”行右侧使用链条按钮一键跟随主模型；不在模型列表中
  混入“与当前会话相同”。点击清除计划模型覆盖，再点不解除跟随，也不切换聊天模式；推理强度保留独立设置。
  计划模型、计划强度与恢复跟随均在同一次设置请求中保留当前交互模式；进入 Spec 由模式选择器单独触发。
- 切换模型、强度或模式时通过控件回显结果，不在聊天输入框上方弹出“正在更新会话设置”；
  保存期间的操作限制和失败反馈照常保留。
- 等级与默认值来自 SDK 当前目录，保留“跟随主聊天”和“模型默认值”；无能力数据时
  不显示强度入口。重选当前模型不重置等级，换模型只保留兼容值。
- 官方／BYOK／全部使用同一个 Host 来源偏好，按目录 `isCustom` 过滤所有相关选择器，
  不清除范围外的已选值。继承项存在时不重复堆空列表说明；加载失败不能伪装成无结果。
- 搜索保留空格编辑、IME、方向键、Tab 与 Escape。菜单开合和焦点返回交给 Radix。
  主聊天、计划、BTW 模型及“＋”菜单搜索框聚焦时保持分隔线原色，不加亮底线。
- Fast、Context 不复制参考产品的开关。SDK 0.9.1 的压缩模型无独立推理强度；升级后
  以该操作实际契约重新核对，不从模型名称推断能力。

## 管理页

- 窄侧栏固定常规、模型、智能补全、会话、任务；选中项使用圆角滑动背景，收展 200ms，
  图标位置稳定、文字同步淡入淡出。窄窗口显示图标列，名称用 Tooltip 和无障碍标签保留。
- 语言与主题在一个分组内使用单条分隔。版本和连接详情放在常规页，不重复挤入主聊天。
- 会话、模型和任务的搜索与筛选放在同一工具栏。会话范围用一个下拉；任务搜索标题或仓库。
  分页默认 10 条，可选 20／50 条；筛选后回首页，少量记录仅显示数量。
- 首次列表加载使用与表格对齐的静态占位；刷新保留旧行和计数，失败保留内容与错误。
  不叠加整页和列表的淡入造成短暂空白；加载结束前不能显示“空列表”。
- Mission 表格保留标题、仓库、电脑、进度、创建时间；状态在标题下，进度附完成数，
  缺失数据用“—”，窄屏可横向滚动。
- 模型页顶部创建渠道，渠道内添加模型继承该渠道；发现、导入、别名、验证、启停与删除
  沿用原 Host 行为。简化样式不能移除禁用原因或必需确认。

## 主题与动效

- 手动 Light／Dark 使用 Factory 预设：浅色页面 `#ffffff`、正文 `#181818`；
  深色页面 `#121212`、正文 `#ffffff`；强调色 `#ff5a00`。来源为 2026-10-05
  Factory 公开应用预设，当前映射见 `src/webview-v2/styles/factory-theme.css`。
- Auto 使用编辑器配套的前景／背景；输入、引用、代码、弹层从同一主题派生，
  不把按钮底色当页面或正文底色。公共包不能依赖 VS Code 变量才能工作。
- 主题切换使用 260ms 整页淡入淡出，首帧不播放切换动画，快速操作以最后选择为准。
  浏览器 `/live` 在解析 HTML 时恢复本标签页最近主题，Host 到达后仍以真实配置为准。
- 导航的背景型指示用 `--control-surface-active`，在深浅主题都应可辨识；滑动 220ms。
  不以接近页面底色的专用黑色覆盖共享 token。
- 控件颜色变化使用共享时长，菜单仅轻量淡入／淡出，不做装饰缩放。状态动画表达实际
  工作或连接状态；减少动画偏好下直接显示结果，静态选中与焦点仍然清晰。

## 主聊天与滚动

- 正文沿用紧凑 13px；页头约 36px、图标按钮 24px、附件缩略图 36px。页头保留品牌、
  连接点、新建、历史和管理入口；连接状态文字仅通过悬停提示与无障碍名称表达，异常时给出统一重连按钮。
- 恢复提示不常驻挤占 Composer 上方；已有历史保持可读，空会话可居中显示等待。
  重连不重发消息，成功以真实握手为准，Stop 未确认不能画成已结束。
- 输入默认与操作控件保持一行，窄面板不强制展开，占位文字超宽时截断；仅实际内容换行
  或空输入首次 Shift+Enter 时展开，清空后恢复一行。单行隐藏 Auto 等模式入口，展开后显示。
  上下文圆圈、模型和发送按钮作为紧凑操作组靠右，组内固定 4px 间距；模型按内容收紧，
  长名称在可用宽度内截断，不在窄面板中拉伸按钮占位。剩余宽度留给输入区域。
  输入在引用标签完整渲染后按实际宽度测高；测量副本保留与真实输入相同的布局属性，
  不改变 Enter、IME、附件准备门禁与队列语义。发送失败保留用户草稿。
  排队消息在编辑期间离开队列时，未保存的文字合回普通草稿并提示，不自动发送；
  未修改的排队内容不重复恢复，主动保存和取消仍回到原草稿。
  行内输入框开始 IME 组字时立即隐藏占位文字，组字结束且仍为空时恢复；组字过程中不重建编辑内容。
  引用标签等嵌套控件自行处理键盘操作；组字期间及 keyCode 229 事件在共享输入层阻断业务快捷键，
  不触发发送、撤销或关闭。组字结束后的普通 Enter 保持原有发送语义。
  浏览器为光标保留的末尾占位换行不计入草稿；主动换行保留可见光标位置，清空后恢复单行输入高度。
- 终止事件到达后的改动记录收尾与下一次发送共享同一个最终快照任务；新发送先等收尾，
  不用可能滞后的后台运行状态拒绝消息。没有本地收尾或已完成快照时，恢复旧回合仍须确认后台空闲。
  取消新发送不取消上一轮的改动记录；收尾失败时保留错误，不带着缺失基线继续发送。
- 输入框上方的 Agent、消息队列、文件变更面板统一以 Agent 的紧凑密度为准：
  标题行 22px、普通条目最小 24px、正文行高 18px，复用共享尺寸 token；
  标题操作按钮不能撑高整行，面板不额外叠加上下留白，引用与活动详情按内容展开。
- 近底发送保持底部；用户上滑、选择文字或操作嵌套滚动区时取消自动跟随。
  显式跳底可平滑滚动，减少动画时直接到达。不能靠空白补位掩盖错位或丢内容。
  工作／回复／压缩／子代理等待提示在实际回到底部后才固定；从历史位置发送或跳转期间仍留在回复末尾，
  不能把“准备跟随”当成“已到达底部”。底部流式跟随时保持提示稳定，短对话紧接正文。
  运行提示自行承接列表底部留白，实色背景延伸至滚动区底边，正文不能从提示下方空隙露出。
- 历史问题按所属轮次吸顶、由下一问题推离。Plan 归属创建它的问题，完成仍保留摘要，
  新计划不删旧计划；回复操作归属整次回答的末尾，运行中不提前显示完成操作。
  问题卡片中的计划摘要行保持 28px 高，不叠加容器上下留白；字号、计数与展开步骤保持原有层级。
  消息时间默认显示相对时间；悬停提示使用紧凑数字日期与本地时间，不附带时区文字。
  吸顶问题进入或退出编辑时，在绘制前同步卡片与原位置占位高度；推离距离使用同一帧的实际列表边界。
- Markdown 引用使用透明底、柔和侧线；代码块和 Diff 使用共享高亮。正文可以完整选择、
  复制，未知语言保留纯文本。长内容的虚拟化不能截掉真实正文或冒充完整历史。

## 引用与 BTW

- BTW 只读：隐藏 fork 加载前检查实际工具目录，只保留文件读取、搜索及明确的内置查询工具。
  编辑、命令执行、委派、自动化变更与未能确认只读的 MCP 工具均禁用；不能建立限制则不发送问题。
  Process／Daemon 每次提问均保留禁用列表与关闭自主执行的设置，重连沿用加载策略，不改变主会话。
  Review 选区问答继续禁用全部执行工具。回答语气和界面不因权限调整而改变。
- 带确认来源的代码使用共享行内编辑器与 `CodeReferenceChips`，只显示文件名与行号。
  引用插入光标处，可与文字交替排列；删除、撤销、发送、排队与编辑重发都保留各段顺序。
  引用按一个字符参与左右移动、Shift 选择与退格／Delete；首尾及连续引用之间保留可输入的
  光标位置。DOM 光标占位不进入草稿、剪贴板或模型输入，标签内部的键盘操作仍归标签处理。
  主聊天和 BTW 点击引用在编辑器定位；Review 中点击引用滚动到当前比较的对应 before／after
  行范围并短暂高亮，不跳转外部文件。当前比较没有该文件时明确提示。
  草稿保存复制当时的完整代码快照，模型输入仍包含路径、范围和代码，不在发送时重读文件。
  长度限制按完整快照与正文计算，替换引用先释放被选内容占用的空间；超限只限制新插入的部分，
  不截断光标后已有文字，也不拆开字符的代理对。原生输入、IME 完成和粘贴使用同一规则。
- Diff 选区“提问”首次打开即带入选中代码引用，光标置于引用后继续输入；未知行号保留代码原文。
  提问入口保持 28px 高，选区与定位反馈复用主题链接色，减少默认深蓝色大块遮挡。
- 自有 Diff 从原始行数据复制单侧代码，保留 before／after；绝对行号未知或跨越未展示的
  区间时保留普通文本。真实编辑器由 Host 记录实际复制，按复制标识和文本匹配，不能凭
  当前选区猜来源。来源缺失、过期或不匹配时照常粘贴文本；异步识别不得覆盖后续输入。
- 多段引用以紧凑摘要块展示，点击查看可滚动的完整原文；删除独立于展开。追加引用
  不覆盖已有输入，超限明确反馈。选区动作执行前重读当前选区，不引用控件或输入框文字。
- BTW 复用主聊天的问题、正文与代码展示，不重复 You／Droid 标签。页头和 Composer
  固定，问题在自己的回合内吸顶；长问题与引用在卡片内滚动。
- 等待、思考、工具和正文状态来自真实事件，不编造耗时；缺少思考文本不显示空折叠。
  准备时问题立即可见，结束后才清理运行提示。
- 关闭仅隐藏，不停止回答或清空同会话草稿；切主会话再清理。Host 接受后只清本次
  提交的内容，失败或未确认保留文字、图片和模型选择，不自动重复提交。

## Review 与恢复

- 聊天中的改动归属来自成功工具操作。工作区净差、路径相同或快照变化不能证明 AI 作者；
  缺补丁明确说明。进行中的单文件行结束后汇总到所属轮次，不挪用其他轮次。
- 工作台区分 Recorded edits、Agent Turn 与 Git 比较；文件、历史、上下文与版本必须
  对应真实范围。旧片段不能用现在的磁盘全文补造；完整可读不等于可撤销。
- 文件列表和代码区独立滚动，分栏保持行对齐且各自横向滚动；长路径不撑破布局。
  保留阅读位置、范围切换、完整性提示及键盘导航，加载时不反复清空已有内容。
  文件折叠时仅保留外层 1px 底边，标题栏底边隐藏，避免两条相邻边框叠粗。
- 合并／分栏与上一处／下一处更改直接放在紧凑工具栏；不在更多菜单重复这些操作。
  文件列表、代码纵向滚动及问答历史复用共享 ScrollArea，事件与虚拟化绑定真实 viewport。
- Review 行内问答使用可拖动、缩放的紧凑面板；正文采用代码批注布局，以“你”与 Droid 图标标签
  区分问题和回答，不添加左侧竖线或消息气泡。问题使用正文色，角色标签使用弱化色，正文连续流式呈现，
  保留中文和 emoji 完整性。能力与生命周期见 [REVIEW](REVIEW.md)。
  头部仅保留标题、恢复原位与关闭；移动／缩放通过拖动和方向键完成。恢复原位不清草稿或重置尺寸。
  标题拖动区保持透明，不显示整条按钮底色或焦点框；键盘聚焦以标题下划线标识，保留方向键和 Escape 操作。
  首次打开采用紧凑输入高度，提交问题后展开回答区；手动调整过的尺寸优先保留。有历史后分出独立滚动区，
  代码块使用柔和底色，复制操作在悬停或键盘聚焦时显示；追问输入与发送操作同排，以顶部细分隔线连接历史，
  不嵌套独立输入框边框。代码引用、草稿和错误反馈保留，边框、圆角及发送按钮复用共享 token。
- Review 讲解先回答具体场景和行为后果，再说明必要机制；默认两到三个短段，少量代码名供定位，
  复杂度不作为逐行复述、罗列类型和内部字段的理由。用户要求深入时展开，追问只解释新问题。
  改前／改后比较必须有对应证据；核对分支方向、执行顺序与取消条件，区分代码事实、注释及推测。
  只读子会话继续禁用工具，提示词要求直接依据选区与相邻差异解释，不调查仓库或输出工具调用。
  写法参考 [explain-diff](https://github.com/Chris-Graffagnino/explain-diff) 的行为与证据原则，
  以及 [explain-it](https://github.com/ankitvashisht12/explain-it/blob/main/references/writing-guide.md) 的具体场景与术语解释原则；
  不引入其完整报告、HTML 或测验流程。实际易读性需用真实模型回答评估，提示词本身不能保证正确。
- 操作 Undo 与历史 Restore 分开。恢复需有可逆证据并检查后续修改；失败保留真实结果，
  不自动重发。历史编辑菜单保留 Resend 和 Restore & resend，文件明细不额外执行操作。
- Git Commit 保留范围、暂存区与实际内容核对，不把 UI 按钮点击当作提交成功。

## Mission 与子代理

- 普通 Task 是只读 Viewer；Mission Worker 在支持的运行模式下打开真实 child 聊天。
  卡片归属原轮次，后台未结束任务不会因父回复完成而隐藏；未知状态不伪装成功。
- 状态、时间、工具数和最新活动只用真实数据，不用代理类型冒充模型名。
  打开失败可重试，关闭标签不停止任务或取消待回答的权限请求。
- Worker／Validator 继承当前编辑中的 Orchestrator；显式等级只保留兼容值。
  创建表单与草稿保留，保存默认设置不改当前 Mission。
