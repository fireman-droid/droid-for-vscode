## 目标与当前授权

主聊天以答案为主，同时支持运行时了解当前动作、完成后简短回顾、展开后追查有用依据。
这是一项跨数据投影与呈现层的连贯功能，不按 CSS 修补处理，也不预设重写 Runtime。

已确认：

- 保留同一消息内连续思考与现有探索工具的稳定分组，不跨正文或非探索工具重排。
- 使用中性 Activity 摘要；统一真实活动、待确认、完成、失败和停止的展示规则。
- 过程展开后思考直接可读、工具行简洁；只有实际详情才提供二级展开。
- 新增真实结果片段只覆盖 Read、Grep、Glob、LS，随本地会话有界保存，优先保留答案。
- 采用现有工具记录内的小型可选结果数据，不新建结果数据库或按引用加载服务。
- 命令、变更、权限、问答保持各自的专用展示与行为。

本规划只获文档编辑授权，不得据此实施过程区产品代码、测试、模拟场景、依赖或配置。
用户随后明确要求将本轮已有 UI 改动与设计文档一并提交到本地 Git，作为离开前的
checkpoint；此授权不包括远端推送、安装、新增验证或过程区实现。此前 UI 改动保持
原样，不为提交继续改功能。文档审阅通过也不自动授权代码实施或验证，下一步单独
确认执行范围。默认由当前代理处理；本规划没有授权 Worker、Mission、SDK 升级或报告整改。

## 实施依赖顺序（尚未获执行授权）

### 1. 稳定共享契约、来源与预算

- 在工具记录上定义可选结果数据，明确文本、可信来源、显示端截断和不可用原因的组合。
  不把详情可用性并入工具成功/失败状态；旧记录没有字段仍然合法。
- 单条文本、行数和 Conversation 总量采用 DESIGN 中确认的初始预算，常量只定义一处。
- 定义先淘汰较早片段、保留操作记录和淘汰原因的共享规则，正文继续沿用现有自身上限。
- 先确认所有预算入口，包括实时 transcript、快照、恢复、历史补齐和只读消费者；
  不能仅在界面截断而允许 Host、持久化或预处理无限增长。
- 结果来源使用明确的当次调用信息；不把用于修改文件的 filePath 重解释为所有工具来源。

### 2. Runtime 有界提取与历史一致性

- 对四类已知本地工具建立明确输入/返回识别规则；不能只按同名叶子把第三方工具接入。
- 从实际 tool_result 文本提取，不通过额外文件读取、重新执行或模型调用补写。
- 在连接或复制大型输出之前限制处理量；保留换行，对控制字符做显示清理。
- 来源不可信、已识别的敏感路径/内容、图片或不支持的结果类型不进入新文本通道。
  清理终端噪声不等于敏感信息过滤，不能宣称存在通用的无遗漏脱敏。
- 实时与历史共用提取规则。保留现有失败错误和图片通道，避免同一结果重复展示。
- 具体工具返回格式要以当前 SDK 类型及可核实的样例为依据，不能从 Studio 截图推定。

### 3. Host 归属、保留与恢复

- 将片段关联到 Conversation、回合、具体工具调用；保持现有旧会话/旧回合隔离。
  重复事件不得重复追加，迟到结果不得覆盖其他调用。
- 通过现有 transcript 与 canonical Conversation 保存小型结果数据，不新建平行存储。
- 所有入口保持预算一致；达到配额先移除较早片段，不因片段增加而额外裁掉正文。
- 旧记录只有存在实际历史结果且来源可靠时才补齐，不覆盖已保留的当次片段。
- 预算淘汰原因随记录恢复，历史补齐不能把主动淘汰的片段反复填回来。
- 会话记录裁剪、删除或切换的生命周期同时管理附带结果，不留下独立悬空缓存。
- 结果不进入诊断日志/导出，命令 outputTail 继续保持原来的非持久化策略。

### 4. Bridge、Webview Store 与 adapter

- Host 与 Webview 两侧校验新增字段及边界，拒绝不合法组合；恢复解析兼容旧记录。
- 接通实时更新、完整快照和历史恢复，保留稳定身份、来源和可用性原因。
- adapter 不伪造原始 args 或通用 result，不改变正文、图片、问答记录和消息顺序。
- 过程层接收有关回合的待确认/待回答事实；历史段不继承当前全局 busy 状态。
- 详情重内容只在实际展开时挂载；文本预算独立不代表可以在每次增量中复制全部片段。

### 5. 过程摘要、工具行与布局

- 实现 DESIGN 中的 Activity 摘要与状态规则：按调用次数统计，不猜文件数或总命中数。
- 保留原有分组边界和手动选择；新增结果、完成、失败或主题变化不重新分组。
- 思考直接展示，工具行去掉重复路径、进度次数与最后事件类型。
- 区分当前文件入口和当次结果入口。无有效详情时不显示箭头，不能点出空容器。
- 统一组内左边界和间距，工具结果只增加一级缩进；不降低整块字号来掩盖信息过密。
- 延续现有滚动所有者与减少动态效果支持，不抢阅读位置、不重播历史文本。

### 6. 共享消费者、产品文档与交付

- 覆盖主聊天、历史恢复、只读子代理窗口；只读窗口不得新增授权、修改、重新执行能力。
- 若某消费者没有可靠等待事实，使用中性的状态，不能借用另一个会话的状态。
- 同步实际能力与限制，不把模拟预览、类型通过或文档批准当作工程完成。
- 安装、提交与推送需获得新的明确授权；当前混合 UI 工作区不能顺带打包成虚假的原子提交。

## 拟议验收与验证范围（未运行、未授权执行）

| 行为 | 必须保护的结果 |
| --- | --- |
| 思考与查询交替、单工具、多工具 | 稳定连续分组、原顺序、展开选择不丢 |
| 正文、图片、修改、命令和交互边界 | 不跨边界合并或搬动记录 |
| 并发与等待确认同时发生 | 待办准确，仍运行的工具不被描述为全部暂停 |
| 单项失败、回合成功、用户停止 | 工具和回合状态独立，不因正文到达而掩盖异常 |
| Read/Grep/Glob/LS 返回文本 | 仅展示当次受限片段，来源明确，无推测的范围或总数 |
| 空文本、截断、旧记录缺失、不支持 | 区分原因，不伪造零命中、完整结果或成功详情 |
| 同一路径反复调用、重复和迟到事件 | 不串工具、回合或会话，不重复保存 |
| 超长单条、大量调用、配额用尽 | 提取与保存有界，先裁片段，不额外淘汰答案 |
| 保存失败及 Reload/历史补齐 | 沿用 durable 写入语义，旧记录可读，主动淘汰不反复回填 |
| 快速展开收起、虚拟列表卸载返回 | 不丢选择、不留下不可见焦点、不抢滚动 |
| 三主题、320px/400px 与常规宽度 | 路径和内容不挤坏布局，状态与焦点可辨 |
| 只读子代理窗口 | 共享展示规则，不增加写操作或串入父会话等待状态 |
| 非覆盖工具与命令输出 | 不新增结果通道，不意外开始持久化命令日志 |
