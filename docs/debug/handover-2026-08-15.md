## Bridge v21：Agent activity

W→H：

- `agentActivity.panel { open }`
- `agentActivity.openTranscript { activityId, requestId }`

H→W：

- `agentActivity.sessions`
  - `ready { entries, windowSaturated }`
  - `unavailable { reason }`
- `agentActivity.transcript`
  - `{ activityId, requestId, status, title, items?, truncated? }`

`AgentActivityEntry` 只有：

- `kind: "automation-session"`
- `activityState: "updated-recently" | "unknown"`
- `stateSource: "modified-time" | "none"`

Host 以 panel generation、workspace generation、cwd、known-list
membership 和 requestId 共同防止关闭、换目录及 A→B→A 旧响应回写。
列表和 transcript 都是 single-flight，并保留一个最新 trailing
refresh；recent 转 unknown 时 Webview 再做一次最终 transcript
刷新。
