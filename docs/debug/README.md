## 维护约定

1. **新反馈按四方向入档**：先判断归属，再写入对应文档；不要塞回总杂烩清单。
2. **完成打钩并写版本号**：落地后改状态为「已完成」或「待实机验收」，并注明版本（如 `v0.7.25`）。
3. **状态词统一**：`已完成` / `待实机验收` / `未做` / `部分` / `待验证`。
4. **截图路径**：相对本目录的 `image/…`；新增截图放 `docs/debug/image/`。
5. **跨方向关联**：可互相引用编号（如 8↔19），但未完成项只在主归属文档跟进。
6. **验收**：剩余未做项全部做完后再统一装包验收（样式决策，见 style-refactor）。
