# 反馈问题

新问题提交到 [GitHub Issues](https://github.com/fireman-droid/droid-for-vscode/issues)，
或在当前协作中提供复现。这里保留提交格式，不再维护第二份本地 Bug 列表；
已确认的当前工作统一放入 [PLAN](PLAN.md)。

```markdown
## 现象
实际发生了什么，预期应该怎样。

## 复现
1. 从哪个页面、什么状态开始。
2. 执行哪些操作。
3. 在哪一步发生问题，是否稳定复现。

## 环境与证据
- 扩展版本与编辑器版本：
- 操作系统、Droid CLI 版本、运行模式（已知时填写）：
- 截图或错误摘要：
```

只提供与问题有关的信息。截图和诊断先移除密钥、连接 Token、私有路径及无关对话内容。
连接或状态问题可先阅读 [排障指南](TROUBLESHOOTING.md)。
