## Cursor Browser MCP

### 活动 Browser Bridge 与目标工作区不一致

- 类型：Bug
- 状态：未处理
- 版本：cursor-browszer-mcp 1.2.3
- 现象：按 DroidVisX 工作区打开页面时提示没有匹配的 Browser Bridge；
  当前唯一活动 Bridge 属于另一个 Cursor 工作区，需要先列出窗口并显式选择
  活动实例。
- 复现步骤：
  1. 同时打开多个 Cursor 工作区，但只在其中一个窗口启用 Browser Bridge。
  2. 从另一个工作区按本地路径调用 `browser_open`。
  3. 观察到 `No bridge matched workspace`。
- 期望：能够明确显示可用窗口并快速选择，或在只有一个活动 Bridge 时提供
  可确认的回退方式。
- 截图或日志：2026-08-31 Live Webview 调试时复现；不记录 Bridge token。

### 长会话的完整交互快照过大

- 类型：功能
- 状态：未处理
- 版本：cursor-browszer-mcp 1.2.3
- 现象：Live Webview 长会话返回 224 个可交互节点，完整快照包含大量历史
  Tool、Thinking 和消息操作，定位底部 Review 面板时输出冗长。
- 复现步骤：
  1. 打开包含较长历史的 `/live` Webview。
  2. 等待 Bridge 加载真实会话。
  3. 请求完整 interactive snapshot。
- 期望：支持按元素引用、选择器或可见区域获取局部快照，便于集中调试
  Review、Composer 等单一界面。
- 截图或日志：2026-08-31 Live Webview 快照，224 个可交互节点。

### Plan 操作菜单超出可用边界

- 类型：Bug
- 状态：未处理
- 版本：DroidVisX 0.7.89
- 现象：在窄宽度 Webview 中展开 Plan 的操作按钮后，选项菜单超出卡片和
  可用视口边界，覆盖周围内容，部分菜单内容接近或越过可见区域。
- 复现步骤：
  1. 在 Cursor Secondary Sidebar 中显示带操作选项的 Plan。
  2. 保持较窄的侧栏宽度。
  3. 展开 Plan 操作按钮的选项菜单。
- 期望：菜单根据可用空间选择展开方向，并限制在视口内；高度不足时内部
  滚动，所有选项文字和点击区域保持完整可见。
- 截图或日志：2026-08-31 用户截图，菜单展开后明显越过 Plan 卡片边界。

### 命令卡省略号操作独占空行

- 类型：样式
- 状态：未处理
- 版本：DroidVisX 0.7.89
- 现象：展开 Execute 命令卡后，省略号操作按钮位于命令标题与输出之间的
  独立横行。该行除右侧省略号外没有内容，形成明显空白并打断标题到输出的
  阅读关系。
- 复现步骤：
  1. 展开包含终端命令和输出的 Execute Tool 卡片。
  2. 观察命令标题下方、输出上方的省略号操作区。
- 期望：省略号应与命令卡标题或其他操作处于同一工具栏，不为单个按钮额外
  占用整行高度。
- 截图或日志：2026-08-31 用户截图，省略号单独位于一条空白横栏右侧。

### “在终端中查看”操作与命令卡脱节

- 类型：样式
- 状态：未处理
- 版本：DroidVisX 0.7.89
- 现象：“在终端中查看”显示为命令卡下方独立的全宽行，与对应命令输出之间

- 截图或日志：2026-08-31 用户截图，“在终端中查看”单独占据卡片下方一行。

### Exploring 当前活动文字未垂直对齐

- 类型：样式
- 状态：未处理
- 版本：DroidVisX 0.7.89
- 现象：Exploration 汇总行中的 `Exploring` 与右侧当前活动文字（例如
  `Thinking`）没有共享视觉基线，次级文字看起来偏上或偏下。
- 复现步骤：
  1. 让 Droid 进入带当前活动的 Exploring 状态。
  2. 观察圆点、`Exploring`、分隔点和当前活动文字的垂直位置。
- 期望：箭头、状态圆点、主文字、分隔点和次级活动文字在同一行内保持稳定
  的视觉居中与文字基线。
- 截图或日志：2026-08-31 用户截图；`.dvx-activity-group-summary` 使用
  `21.125px` 行高，而 `.dvx-activity-group-current-slot` 固定为 `17px`
  行高，内部 `.dvx-activity-group-current` 另设 `vertical-align: top`。

### Plan 已完成项删除线不明显

- 类型：样式
- 状态：未处理
- 版本：DroidVisX 0.7.89
- 现象：Plan 中已完成步骤虽然带勾选和删除线，但暗色主题下删除线与灰色
  文字的对比度过低，快速浏览时很难区分已完成项和普通弱化文字。
- 复现步骤：
  1. 打开包含 completed 与 in-progress 步骤的 Plan。
  2. 在暗色主题下比较已完成项与当前步骤。
- 期望：保留克制的完成态，同时让删除线在暗色和浅色主题中都清晰可辨，
  不只依赖圆形勾选图标表达状态。
- 截图或日志：2026-08-31 用户截图；暗色覆盖将
  `.dvx-plan-step-completed .dvx-plan-text` 的删除线颜色设为
  `rgb(255 255 255 / 30%)`，并同时使用 muted 文字色。
