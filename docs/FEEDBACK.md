```markdown

- 类型：Bug / 样式 / 功能

- 版本：

```

## 记录规则

1. 一项问题一个小节。
2. 只写现象、复现、期望和证据。
3. 不在这里写实现方案、测试计划或每日进度。
4. 完成后保留一行结果，详细变化写 `CHANGELOG.md`。
5. 当前执行顺序只在 [`PLAN.md`](./PLAN.md) 维护。
