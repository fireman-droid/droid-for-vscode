最近一直在用 Droid，也折腾了一套自己的 GUI。

做它的原因其实挺简单：之前用过的一些 GUI，给我的感觉是元素太多，按钮、状态和各种面板挤在一起，页面看着有点繁重，也不太符合我的审美。

我自己更喜欢 Cursor 原生聊天那种感觉：聊天区干净一点，工具细节需要时再展开，改了哪些文件、具体改在哪里，都能顺着当前任务看下去。

所以就做了现在这个项目，名字叫 **Droid**。界面和交互尽量贴近我习惯的编辑器体验，同时加上完整 Diff、BTW 侧聊、代码补全这些自己日常会用到的功能。

## Droid 是什么

Droid 是一个运行在 **VS Code / Cursor** 里的 **Factory Droid CLI 非官方图形界面插件**。

可以直接在编辑器里和 Droid 聊天、让它查看项目和修改代码，过程中查看工具执行、确认权限，结束后再审阅文件改动。

底层聊天和任务执行复用本机的 Droid CLI / SDK。这个项目主要负责把这些能力做成更清楚、顺手的编辑器界面。

GitHub：[fireman-droid/droid-for-vscode](https://github.com/fireman-droid/droid-for-vscode)

使用说明：[README](https://github.com/fireman-droid/droid-for-vscode#readme)

## 我比较想做好的几个地方

### 更接近 Cursor 原生的界面体验

主要精力花在了聊天页面的布局和信息展示上。

回复、思考过程、工具执行和文件修改分别展示，详细内容按需展开。任务计划、待发送消息、子代理状态也有各自的入口，尽量让注意力留在正在处理的问题上。

这里说的“像原生”，指的是布局和操作习惯接近 Cursor；插件本身是独立实现的，也可以在 VS Code 中使用。

### 完整 Diff，连上下文一起看

我自己很在意的一点是：**一个文件被改了，审阅时应该能看到整个文件，并在改动位置标出 `+` 和 `-`。**

所以做了独立的 Review 页面，支持完整文件对照、统一／左右分栏视图，以及修改位置跳转。既能从聊天中的某次文件修改进入，也能集中查看这一轮的改动。

这样看修改时，可以连着前后的代码一起读，更容易判断这次改动是否合理。

完整文件展示需要有对应的版本记录；部分旧会话如果只留下了修改片段，界面会明确标出来。

### BTW：主任务之外，顺便问一句

比如 Droid 正在帮我改代码，看到回复中的一个概念，我可能只是想问：

> 这里为什么要用这个方案？这个参数又是什么意思？

这时候就可以用 **BTW（By the Way）侧聊**，围绕已有对话的上下文单独提问，把这段讨论留在旁边。

支持选中文字后引用提问，也支持图片和单独选择模型。看完关掉侧栏，就可以继续看主聊天。

### 代码补全和 Next Edit

除了聊天，也接了编辑器里的代码补全。

- **灰字补全**：输入代码时给出续写建议，`Tab` 接受，`Esc` 关闭。
- **Next Edit**：预测接下来可能要修改的位置，查看修改提示，再跳转或接受。
- **随时暂停和恢复**：从状态栏控制，不需要每次进设置找开关。

补全默认关闭，需要单独配置支持的模型服务。普通续写支持 Codestral、DeepSeek 兼容 FIM、Ollama 等接入方式，Next Edit 已接入 Mercury；实际效果和速度取决于所用模型及服务。

## 还有哪些功能

模型管理支持 **官方、BYOK、混合** 三种显示范围，可以给服务商和模型改别名，也能暂时禁用某个配置，再恢复使用。中转服务需要兼容 Droid 支持的接口协议。

子代理可以从任务卡片打开，查看执行过程；在 daemon 模式下，也能进入对应的子会话继续聊天或停止任务。Mission 的任务进度和 Worker 入口也已接入。

另外还有文件／图片附件、Skills、MCP 和插件管理，以及 Markdown、公式和 Mermaid 图表展示。这些都放在同一个扩展里，聊天和代码补全使用同一份安装包。

## 怎么使用

1. 先安装官方 **Droid CLI**，完成本机认证，确认所选模型可以正常使用。
2. 从 [GitHub Releases](https://github.com/fireman-droid/droid-for-vscode/releases) 下载 `.vsix`，在编辑器扩展面板选择 **Install from VSIX**。如果还没有可下载版本，可以按 README 从源码构建。
3. 执行 **Developer: Reload Window**，打开 Droid 侧栏开始使用。需要代码补全时，再单独配置并启用。

插件原创代码采用 **MIT** 许可证，第三方代码保留各自的许可。它是个人维护的非官方项目，不包含 Factory 订阅或模型额度；聊天、BYOK 和补全的费用取决于实际使用的服务。

目前主要在 Windows 上开发和验证，其他平台的体验还需要继续完善。

项目还在持续打磨中，尤其想听听大家对界面、Diff 审阅和日常操作的反馈。哪里看着别扭、操作不顺，欢迎提 [Issue](https://github.com/fireman-droid/droid-for-vscode/issues)，也欢迎贡献 PR。
